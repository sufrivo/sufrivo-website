# Sufrivo Website

Responsive static marketing website implementing the Sufrivo Figma design. GitHub Pages/Jekyll-compatible without a build step.

## Pages
Home, Products, eight product details, Pricing, Industries, Integrations, About, Contact, Demo, Help, Privacy and Terms.

## Pricing
All AED figures are illustrative planning concepts and are explicitly labeled as such; commercial approval is required before publication.

## Lead form
The demo form validates fields and opens a prefilled email draft; it does not send data to an API. Replace the mailto fallback with an approved backend endpoint before launch. Verify the recipient mailbox exists before publishing.

## Localization
The language switch provides Arabic homepage copy and RTL layout scaffolding. Complete translation of all content is still needed before claiming full bilingual support.

## Assets
The hero dashboard and kitchen ticket preview are CSS-rendered illustrations. Original Figma photographs have not yet been committed as binary assets.

## Local preview
Run a static server from the repository root, for example `python3 -m http.server 8000`, then visit http://localhost:8000.
