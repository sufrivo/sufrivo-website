## Primary search intents
- Homepage: restaurant management software / connected restaurant platform
- POS: restaurant POS system / table service POS
- KDS: kitchen display system for restaurants / kitchen order tickets
- Ordering: QR code ordering system / digital restaurant menu
- Kiosk: self-service restaurant kiosk software
- Reservations: restaurant reservation and waitlist software
- Staff: restaurant staff scheduling software
- Management: multi-location restaurant management software
- Industries: software for cafés, QSR, cloud kitchens and food trucks

## Implemented
Unique metadata for commercial pages; canonical and social metadata; structured data without fabricated reviews or prices; sitemap and robots; original homepage explainer and contextual product links.

## Release checks and next work
1. Validate all route metadata, JSON-LD, sitemap URLs and client-side rendering; check mobile layout and keyboard navigation.
2. Add static HTML or prerendered meaningful content on each product page so crawlers do not rely exclusively on JavaScript.
3. Expand product pages with verified workflow details, authentic screenshots and helpful FAQs, without suggesting unshipped features are available.
4. Add original educational articles based on real expertise, not competitor copy or keyword stuffing.
5. Verify site ownership in Google Search Console, submit sitemap, inspect indexing and monitor search impressions, CTR and demo conversion.
6. Update canonical domain when moving off GitHub Pages.

Ranking cannot be guaranteed; no fabricated reviews, customer claims, integrations or performance metrics.
